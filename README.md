# VICEVAULT // Official Luxury Gaming Merchandise & Wraps

VICEVAULT is a high-performance, responsive luxury e-commerce web application inspired by Apple glass aesthetics and Vice City gaming culture.

## ✨ Features
- **Luxury Obsidian Glass UI**: Frosted backdrop blur, smooth micro-interactions, responsive mobile-first layouts.
- **Product Catalog**:
  - DualSense Pro Controller Skins (₹699)
  - PS5 Full Console Armor & Wraps (₹1,199)
  - GTA Inspired Large Gaming Mouse Pad / Desk Mat 58.5 x 28 cm (₹499)
  - GTA VI Collectible Keychains (₹399)
- **Interactive Multi-Image Gallery & View Selector**: Seamless image switching, thumbnail previews, dynamic specification sheets.
- **24-Hour Dispatch Countdown Engine**: Real-time batch countdowns tailored per product slot.
- **Complete Cart & 1-Click Checkout**:
  - Instant order summary & quantity manager
  - All-India 36 States & 780+ Districts pre-fill validation engine
  - Dynamic payment modes: Cash on Delivery (COD) & Instant UPI (Dynamic QR Code + UPI Collect Pop-up simulation)
  - Seamless COD to UPI conversion for existing orders
- **Order Management & Live Tracking**:
  - Multi-order tracking with step-by-step progress bars and courier tracking IDs
  - VIP Member profile management & order history
- **Admin Dashboard (`admin.html`)**:
  - Live order monitor, status transitions (Pending, Processing, Shipped, Delivered)
  - Revenue analytics and order management

## 🚀 Getting Started
Open `index.html` in any modern web browser or run a simple local HTTP server:

```bash
# Python 3
python3 -m http.server 3000
```

Visit: `http://localhost:3000`

## 📁 File Structure
- `index.html` - Main store landing page & product catalog
- `product.html` - Dynamic product showcase & 1-click checkout
- `admin.html` - Admin order management console
- `images/` - High-resolution product images & assets
